# 神经元配置与残差流实验

[English](EXPERIMENTS.md) | **简体中文** · [文档目录](README.zh-CN.md)

## 可复用的神经元配置

打开顶部“神经元配置”，创建命名分组，添加操作（层、神经元编号、加法／乘法、带正负号的剂量、是否启用），选择目标组并保存批次。“添加当前神经元”可复制聊天调整。

每次保存记录有序操作、模型及可用 revision、权重格式、计算精度、UTC 时间与备注。“使用”启用批次；使用另一批次会替换前者，“停用”移除效果。同一神经元上的操作依次执行。加法使用聊天中的残差范数单位；乘法为直接因子，0 表示消融。

聊天临时调整叠加在当前批次上，因此评测的基线也含该批次；要比较原始模型，请先停用。“仅对话”把带正负的调整合并为单条流式回复，并支持保存批次；“评测”比较正向、基线与反向输出。

分组和批次以 UTF-8 原子替换方式保存在 `explorer/cache/neuron_batches.json`。刷新页面保留服务器会话中的启用状态；重启或重载权重清除启用状态，但保留记录。再次使用时需匹配模型、revision、权重格式和精度；旧记录未含精度时按 BF16 处理。“复制编辑”生成新记录，在相同模型设置下保存副本须修改至少一项操作。右键可重命名或删除，删除启用批次会停用它。配置不改权重文件。

## 观察残差流

运行短输入并选择 token，打开残差分析。同次采集覆盖全部层与输入位置，切换层、阶段和神经元会复用结果。可查看 pre（层输入）、mid（注意力／混合后、MLP 归一化前）、post（层输出）、注意力与 MLP 更新、完整坐标和正负极值。

地图全景显示分组坐标均值，展开后显示真实维度，全部层共享维度窗口。神经元写入等于实际激活乘以下投影列，通常影响多个维度。向量正负、激活正负和 token 得分变化须分别理解。

局部 token Δlogit 是移除写入前后的透镜差；下一层读取者估计固定注意力输出，重算归一化和 MLP。两者都不重跑全部后续层。JSON 可导出选中 token 的全层原始向量。切换权重或配置后需重新采集。

仅残差采集在 32 层、2560 维、1024 token、16 位数值时约增加 325 MiB 主机内存，完整激活与评分更大，建议从短文本开始。

## 运行因果干预对照

在“运行”中添加最多 8 条独立文本，不会拼接上下文。当前文本控制 token、激活和地图。浏览器记住草稿，但只为当前文本保留大型激活分析。

打开右侧“对话”和“详情”之间的“残差流”，准备 token 后选择层、pre/mid/post、强度与范围：每条文本所选 token、提示末尾、全部提示 token，或持续作用于生成过程。默认用原始文本，启用聊天包装后编号包含模板。每条输入最多 1024 个模型 token，超限报错而非截断；生成 0–128 个新 token。

| 方法 | 效果 |
|---|---|
| 添加方向 | 使用神经元输出方向、两条输入的状态差或完整隐藏维度 JSON 向量。先归一化，再添加 α × 当前受影响位置残差 L2 范数；负值反向，单位与聊天剂量不同。 |
| 移除写入 | 减去本次计算中神经元、整个 MLP、注意力头或整层注意力／混合输出的指定倍数。神经元／MLP 用 post；注意力／头用 mid 或 post。 |
| 去除投影 | 移除归一化方向分量，强度 0–1。 |
| 替换状态 | 用来源文本同层同阶段状态替换／混合目标，强度 0–1。来源和目标 token 分别选取，不把同编号当作语义对齐；持续替换重复使用同一来源向量。 |

每条输入分别运行原始对照和干预组，使用全新缓存和确定性贪心生成。两者均含当前神经元批次，只有干预组增加残差操作。结果展示生成、下一 token 概率、KL、选中位置激活变化与各层残差范数。候选答案每行一条，对完整续写评分，不只首 token（每条 1–64 token）。

可停止并保留完成组，或导出输入、设置、模型元数据和结果。修改设置后旧结果保留并标记为上次实验；切换模型或批次后须重跑。干预 hook 仅在实验范围内生效，不改权重文件。

## 模拟练习

打开 `neuron-explorer-demo.html`，选择“模拟模式 → 试用多文本残差对照”。数据和回复均为浏览器示例，不是真实 Qwen 测量。界面更新后执行 `python explorer/build_demo.py` 同步演示。
